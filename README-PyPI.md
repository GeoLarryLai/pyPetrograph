# pyPetrograph

v0.4.1

pyPetrograph is a Python toolkit for semi-automated, machine-learning-assisted thin-section petrography. It supports pixel classification and area proportions, mineral counting, grain segmentation, and micro-texture analysis, including an AMICS workflow using BSE images, mineral maps, and legends.

A local browser app guides thin-section photo analysis and AMICS grain counting, with review and correction before export. Example notebooks, figures, installation details, and demonstrations are available in the [GitHub repository](https://github.com/GeoLarryLai/pyPetrograph).

**Caution:** The package is under active development. Some methods are experimental or incomplete and require independent checking.

Citation: Lai, L. S.-H. (2026). pyPetrograph. [Zenodo](https://doi.org/10.5281/zenodo.23659316).
